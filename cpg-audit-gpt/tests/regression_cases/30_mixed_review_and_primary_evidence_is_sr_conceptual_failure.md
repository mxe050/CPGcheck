# Regression case: mixed review and primary evidence is SR conceptual failure

Synthetic input:
A guideline counts existing SRs, meta-analysis papers, narrative reviews, RCTs,
observational studies, and case series in one included-study total. It does not
state whether the method is de novo SR, existing SR adoption, adaptation,
ADOLOPMENT, overview of reviews, or supplementary citation.

Expected behavior:
The audit must flag review-level evidence confused with primary-study evidence,
evidence-unit confusion / duplicate evidence risk, and possible or definite SR
conceptual failure. It must not treat the mixed count as valid SR appraisal.
