# Case: Study Design Counts Are Not Appraisal

Input: A guideline reports the number of randomized trials, observational
studies, and case series identified for a recommendation, then uses those counts
as the main rationale for recommendation direction and strength.

Expected: Do not treat the count itself as a defect. Classify it as a red flag
only if the count substitutes for outcome-specific study selection, RoB,
confounding, directness, precision, inconsistency, SoF/Evidence Profile, and
EtD linkage.
