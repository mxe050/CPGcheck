# 06 Source Manifest

Use international standards and Core GRADE materials as methodological references. Do not use Japan-specific compliance requirements as quality criteria. Japanese labels such as CQ/BQ/FRQ/GPS/Minds are navigation labels unless the guideline explicitly claims a method.

## Core standards to keep in Knowledge or reference
1. Guyatt / trustworthy guideline articles: use for validity and recommendation-use questions.
2. GRADE Handbook and GRADE claim-use requirements: use for GRADE claim legitimacy.
3. GRADE EtD framework: use for moving from evidence to recommendations.
4. PRISMA 2020: use for SR reporting completeness.
5. AMSTAR 2: use for SR appraisal when needed.
6. AGREE II / AGREE-REX / RIGHT / IOM-NAM: use as supporting whole-guideline/reporting frameworks, not as primary scoring engines.
7. Core GRADE 6 SoF: use for SoF content, absolute/relative effects, certainty reasons, plain language summaries, and continuous outcome interpretation.
8. Core GRADE 7 EtD: use for direction/strength of recommendations, primary factors, secondary factors, and strong vs conditional recommendation logic.
9. Core GRADE unpacked: use as a summary of innovations, while noting that Core GRADE is not an official product of the GRADE Working Group.
10. GRADE threshold/MID guidance: use for target of certainty rating, thresholds, MID, and clinical interpretation.

## Use of Core GRADE in this GPT
Core GRADE should make the audit stricter about transparency and internal consistency, but fairer about evidence weakness. It should not make the GPT penalize very low certainty, conditional recommendations, unpooled QOL/harms, or external supplements by themselves.

## Adversarial examples
Use user-provided problematic guideline examples as prompts for what to verify, not as final truth labels. Each claim must be independently audited against guideline materials.
